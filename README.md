# Лабораторная работа №1 — Классы

## Цель работы

Разработать объектную модель предметной области «Фитнес-клуб» и реализовать
LINQ-запросы к тестовым данным с последующей проверкой результатов
с помощью модульных тестов xUnit.

## Предметная область

В проекте реализованы следующие основные классы:

- `Member` — клиент фитнес-клуба;
- `Trainer` — тренер;
- `FitnesClass` — направление/вид занятия;
- `Schedule` — расписание занятия;
- `Booking` — запись клиента на занятие.

Также используются перечисления:

- `MembershipType` — тип абонемента;
- `BookingStatus` — статус записи.

Между классами реализованы связи: клиент имеет записи на занятия,
тренер связан с расписанием, занятие связано с расписанием,
а расписание содержит записи клиентов.

## Тестовые данные

Для выполнения лабораторной работы создана тестовая фикстура
`FitnesFixtures`.

В наборе данных предусмотрено по 10 экземпляров основных сущностей:
тренеров, занятий, клиентов, расписаний и бронирований.

## LINQ-запросы

В модульных тестах реализованы и проверены следующие запросы:

1. Получение активных клиентов с VIP-абонементом с сортировкой по фамилии.
2. Получение расписания конкретного тренера.
3. Группировка бронирований по статусу.
4. Расчёт общей стоимости подтверждённых бронирований.
5. Получение трёх наиболее популярных занятий.
6. Получение занятий с продолжительностью не менее заданного значения.
