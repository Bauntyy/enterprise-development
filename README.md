# Лабораторная работа №1 — Классы

## Цель работы

Разработать объектную модель предметной области «Фитнес-клуб» и реализовать
LINQ-запросы к тестовым данным с последующей проверкой результатов
с помощью модульных тестов xUnit.

## Предметная область

В проекте реализованы следующие основные классы:

- `Person` — базовый класс для клиента и тренера;
- `Member` — клиент фитнес-клуба;
- `Trainer` — тренер;
- `Specialization` — справочник специализаций тренеров;
- `Booking` — запись клиента на персональное занятие.

Также используется перечисление:

- `Gender` — пол клиента или тренера.

Между классами реализованы связи: клиент имеет записи на занятия,
тренер связан с записями на занятия, а каждая запись содержит информацию
о клиенте, тренере, дате и времени занятия, названии зала и признаке
пробного посещения.

Для общих свойств клиента и тренера выделен базовый класс `Person`.

## Тестовые данные

Для выполнения лабораторной работы создана тестовая фикстура
`FitnesFixtures`.

В наборе данных предусмотрено по 10 экземпляров основных сущностей:
тренеров, клиентов, специализаций и записей на занятия.

## LINQ-запросы

В модульных тестах реализованы и проверены следующие запросы:

1. Получение тренеров со стажем работы не менее 5 лет.
2. Проверка доступности выбранного зала для записи в данный момент.
3. Получение клиентов с просроченным абонементом с сортировкой по ФИО.
4. Получение занятий за текущий месяц в выбранном зале.
5. Получение пяти наиболее популярных тренеров.
